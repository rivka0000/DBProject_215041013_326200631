# מערכת TransRoute — הסבר והוראות הפעלה מלאות (שלב ה')

מסמך זה מסביר איך להקים ולהריץ את המערכת **מכל מחשב**, מאפס ועד מסך עובד.

---

## 1. מה המערכת עושה?

TransRoute היא מערכת ניהול תחבורה וסיורים מודרכים, הבנויה כאפליקציית ווב:
- **צד שרת:** Python + Flask, מתחבר ל-PostgreSQL באמצעות psycopg2.
- **צד לקוח:** HTML / CSS / JavaScript — ממשק בעברית, מימין לשמאל, בעיצוב נקי בהשראת Apple.
- **בסיס הנתונים:** PostgreSQL — בסיס הנתונים המשולב של שלב ג' (12 טבלאות), כולל הפונקציות, הפרוצדורות והטריגרים של שלב ד'.

### מה יש בממשק?
| מסך | מה עושים בו |
|---|---|
| מסך כניסה | בדיקת חיבור לבסיס הנתונים וכניסה למערכת |
| לוח בקרה | סטטיסטיקות חיות מכל הטבלאות |
| 12 מסכי ניהול | הצגה, חיפוש, הוספה, עריכה ומחיקה (CRUD) לכל טבלה: נהגים, לקוחות, רכבים, מסלולים, נסיעות, תחזוקה, סיורים, מופעי סיור, הזמנות, מדריכים, תחנות, תחנות בסיור |
| שאילתות (שלב ב') | הרצת 4 שאילתות עם פרמטרים והצגת תוצאות |
| פונקציות (שלב ד') | הרצת 2 פונקציות דוח ו-2 פרוצדורות עדכון |

**עקרונות שמומשו לפי הדרישות:** בעריכה — המערכת שולפת את הרשומה לפי המפתח וממלאת את כל השדות אוטומטית; מפתחות זרים מוצגים תמיד **כשמות** (שם נהג, שם סיור, דגם רכב) ולא כמספרי ID; טבלאות גדולות מחולקות לעמודים של 50 שורות.

## 4. שלב ב' — הקמת בסיס הנתונים

> **קיצור דרך עם Docker:** אם מותקן Docker Desktop, אפשר במקום להתקין PostgreSQL להריץ מתיקיית השורש של הפרויקט: `docker compose up -d` — זה מקים PostgreSQL (פורט 5432) ו-pgAdmin (בדפדפן: http://localhost:8080) אוטומטית, ואז ממשיכים לסעיף 4.2 לשחזור הגיבוי.

### 4.1 יצירת משתמש ובסיס נתונים
לפתוח את **pgAdmin** (או psql) ולהריץ:

```sql
CREATE USER tirtsa WITH PASSWORD 'tirtsa' SUPERUSER;
CREATE DATABASE restore_final_db OWNER tirtsa;
```

### 4.2 שחזור הנתונים מהגיבוי
הגיבוי העדכני נמצא בפרויקט בנתיב: `שלב ד/stage4.backup`

**דרך pgAdmin:** קליק ימני על `restore_final_db` ← **Restore** ← לבחור את הקובץ `stage4.backup` ← Restore.

**או דרך שורת הפקודה:**
```bash
pg_restore -U tirtsa -h localhost -d restore_final_db --no-owner "שלב ד/stage4.backup"
```

### 4.3 התקנת תתי-התוכניות של שלב ד'
להריץ על `restore_final_db` את הקבצים הבאים (דרך Query Tool ב-pgAdmin, לפי הסדר):

1. `שלב ד/01_function_transport_tours.sql`
2. `שלב ד/02_procedure_transport_tours.sql`
3. `שלב ד/03_trigger_transport_tours.sql`
4. `שלב ד/05_function_customer_bookings.sql`
5. `שלב ד/06_procedure_customer_bookings.sql`
6. `שלב ד/07_trigger_customer_bookings.sql`

(הקבצים כתובים עם `CREATE OR REPLACE`, כך שבטוח להריץ אותם גם אם חלקם כבר קיימים.)

## 5. שלב ג' — הגדרת קובץ הסביבה

בתיקיית **השורש** של הפרויקט לוודא שקיים קובץ בשם `.env` עם התוכן:

```
DB_USER_SECRET=tirtsa
DB_PASSWORD_SECRET=tirtsa
DB_NAME_SECRET=Transroute
```

> הערה: האפליקציה מתחברת בפועל ל-`restore_final_db` על `localhost:5432`. אם PostgreSQL מותקן עם משתמש/סיסמה אחרים — לעדכן את הערכים בקובץ זה.

## 7. הפעלת המערכת 🚀

### הדרך הקלה — לחיצה כפולה
פשוט ללחוץ לחיצה כפולה על הקובץ: **`שלב ה/TransRoute.bat`**
הוא בודק את החבילות, מפעיל את השרת ופותח את הדפדפן אוטומטית.

### או ידנית משורת הפקודה:
```bash
python "שלב ה/app/app.py"
```

ואז לפתוח דפדפן בכתובת: **http://localhost:5000**

1. במסך הכניסה להמתין להודעה הירוקה **"מחובר לבסיס הנתונים בהצלחה!"**
2. ללחוץ **"כניסה למערכת"**
3. זהו! מנווטים בין המסכים דרך התפריט בצד ימין.

**לעצירת השרת:** ללחוץ `Ctrl+C` בחלון הטרמינל.
